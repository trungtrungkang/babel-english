# Roadmap and backlog

## Priorities around the review meeting

Current iteration: one shopping unit with three activity types and bilingual decision-support documents. Next: Châu/Vic pedagogical review → select a real unit → prepare materials/rubric → consented trial → revise → expand production. Do not add lessons, AI, gamification or a backend merely for the review meeting.


These are milestones, not delivery-date commitments. Estimate after agreeing the team, materials and scope.

## D0 — Idea demonstration

Completed: project setup, living documentation, six Speaking lessons, recording implementation, teacher/parent views, sample content editing, draft/version handling and VI/EN support. Project documentation is now available inside the demo in both languages.

Outstanding: Vic and Châu review the demo and record at least three decisions; test the microphone and playback on the presentation device.

Exit condition: confirm the learning direction and select a pilot audience. D0 does not establish educational effectiveness.

## D1 — Validate the lesson

| Priority | Work | Done when |
|---|---|---|
| P0 | Collect 3–5 representative Babel lessons | Goals, transcripts and media rights are available |
| P0 | Agree age, level and practice schedule | Named group and responsible owner |
| P0 | Observe 5–8 consented trials | Record where help is needed; do not generalise statistically |
| P0 | Try the rubric with two teachers | Identify disagreements and refine criteria |
| P1 | Adjust duration and steps | Changes follow observations |

## P1 — Pilot MVP

| Priority | Area | Main acceptance condition |
|---|---|---|
| P0 | Authentication/enrolment | Correct class/level; cross-account access blocked |
| P0 | Content/CMS | 10–15 approved lessons, templates, previews and versions |
| P0 | Assignments | Class tasks, resume, submission and retry |
| P0 | Audio | Private storage, retention rules and device compatibility |
| P0 | Teacher review | Queue, rubric, feedback and history |
| P0 | Parent view | Correct child links and clear status |
| P0 | Data operations | Consent, deletion, backup/restore and support |
| P1 | Review practice | Simple teacher-adjustable schedule |
| P1 | Measurement | Minimal events tied to hypotheses |

All P0 items must be verified and Babel must approve materials and operations before starting. AI is not a pilot prerequisite.

## P2 — Stable Speaking

Expand classes, optimise teacher workload and assess before/after performance and transfer to new situations. Trial AI as an internal suggestion tool against teacher judgements before exposing it to children.

## P3 — Next skill

Choose Listening or Vocabulary based on the curriculum. Reuse materials and core services. Add Grammar, Reading, Writing and Testing gradually.

## Deferred

Open-ended chatbots, 3D avatars, public leaderboards, teacher marketplaces, payments, separate native apps, microservices and large examination systems.
